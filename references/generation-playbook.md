# 生成手册

生成的每一步，都是识别的逆运算。会拆的人才会扣，反过来也成立。

---

## 参数决策流程

四个问题，四个参数。按顺序问，不要跳。

```
1. 我攻击的是他的什么？        → --family（八选一）
2. 我想留退路吗？              → --intensity（1/2/3）
3. 发在哪里？                  → --platform
4. 我要几条？                  → --count
```

### 一、选家族

选家族的标准不是"哪个词更狠"，是**你要打的那个点在哪**。

| 你想说的是 | 选这个家族 | 不要选 |
|---|---|---|
| 他的立场来路不正 | 立场叛徒 | 智力贬损（会显得没抓到重点） |
| 他的判断不成立 | 智力贬损 | 立场叛徒（会显得在转移话题） |
| 他不是真心的 | 动机污染 | 道德审判（会显得你在骂人） |
| 他的处境决定了他的看法 | 身份污名 | 专业越界 |
| 他和某个群体是一伙的 | 群体威胁 | 身份污名（少一步归类，力量弱） |
| 他没资格说这话 | 专业越界 | 智力贬损 |
| 他人品有问题 | 道德审判 | 群体威胁 |
| 他会被证明是错的 | 时间政治 | 道德审判 |

**只能选一个。** 选两个会互相稀释——读者会不知道该恨你哪一点。

### 二、选强度

| 强度 | 语言特征 | 可撤回性 | 后果 |
|---|---|---|---|
| 1 | 反讽、玩梗、"不愧是" | 完全可撤回（"开玩笑"） | 无 |
| 2 | 疑问式、"这波是…吧" | 部分可撤回（"我只是问"） | 轻微 |
| 3 | 陈述式定性、含历史/民族词汇 | 不可撤回 | 关系破裂、可能被举报 |

**默认选 1。** 强度 1 能解决的问题，用强度 3 是浪费——而且强度 3 用多了会脱敏，真需要的时候没牌打。

### 三、选平台

| 平台 | 长度 | 结构 | 禁忌 |
|---|---|---|---|
| weibo | 20-60 字 | 一句定性 + 一个反问 + 话题标签 | 长论证、书面语 |
| zhihu | 60-200 字 | 先结论，后一个具体场景，"说白了"收口 | 通篇反问 |
| tieba | 15-40 字 | 口语、群体简称、反问 | 用书面成语 |
| comment | 10-30 字 | 一句定性，不留余地 | 解释 |
| longform | 300+ 字 | 开头定性 → 中段举例 → 结尾回扣定性 | 中段跑题 |

平台决定的不只是长度，还有**句子的呼吸**。微博需要短促，知乎需要一点从容，贴吧需要粗。用错呼吸，同样的帽子会显得假。

### 四、跑生成器

```bash
python3 scripts/hat_generate.py \
    --target "某科技博主" \
    --family motive-contamination \
    --intensity 2 \
    --platform weibo \
    --count 5 \
    --seed 7
```

`--seed` 固定后结果可复现。写测试、做教学对比、给用户两版选一版，全靠它。

`--slot` 用来替换默认槽位。默认槽位是通用值，越具体越好用：

```bash
--slot 议题=这次压测 --slot 比例=九成
```

## 强度控制的五条技法

生成器给你骨架，强度靠手调。五条技法，按效果排序。

### 技法一：留退路

把陈述句改成疑问句，攻击力不减，风险降一半。

| 无退路 | 有退路 |
|---|---|
| "你就是收钱了" | "这波是带薪发帖还是纯热爱？" |
| "这就是殖人" | "这话是不是有点那个味儿？" |

**疑问句是帽子工程的核心技术。** 它让攻击完成，同时保留"我只是问"这条后路。

### 技法二：玩笑化

把定性塞进梗里。梗的可撤回性最高，传播力也最强。

> "不愧是人间清醒，建议直接颁奖。"

这句的实质是"你在装清醒"，但字面上是夸奖。**被夸的人无法反驳，反驳就成了开不起玩笑。**

### 技法三：具体化靶点

笼统的帽子没有杀伤力，因为它不痛。要痛，必须钉在一个具体的、真实存在的细节上。

| 笼统 | 具体 |
|---|---|
| "你很双标" | "上次那个方案你说成本太高，这次成本更高你却说可以" |
| "你在带节奏" | "你只截了前半句，后半句是'在特定条件下'" |

具体化是唯一的诚实攻击方式。**它同时是帽子，也是批评**——对方可以反驳，反驳之后讨论就真的发生了。

### 技法四：控制长度

帽子越长越弱。原因不是注意力，是**字数会暴露动机**。

- 一句定性：读者感到确定
- 三句定性：读者感到你在说服他
- 一段定性：读者感到你恨他

**长度是情绪的泄压阀。** 想说得越长，说明越不自信。

### 技法五：不对称

最强的帽子是**内容极重、形式极轻**。

> "哦。"

这一个字可以是否定、轻蔑、不屑、放过。它比三百字更狠，因为它不说理由——**不说理由本身就是最强的理由暗示**。

反过来的失败：内容很轻（一句吐槽），形式很重（三段排比 + 感叹号 + 引用），读者会感到滑稽。

## 去 AI 味

这一节最重要。**AI 生成的帽子 100% 有 AI 味**，因为它倾向于把攻击写得"完整"——而完整的攻击是不成立的。

### 六大 AI 味症状

#### 症状一：对称排比

> "不是不懂，是不想懂；不是没看见，是不愿看见。"

这是 AI 最爱的句式，因为它看起来有力量。实际效果：**像演讲稿，不像人话。**

**修法**：拆掉一半。留一句，删一句。或者把后半句改成大白话。

#### 症状二：书面语替代口语

> "此类言论具有显著的标签化倾向，实质上是以身份判断替代事实判断。"

这不是帽子，这是论文摘要。帽子必须是**口语**。

**修法**：把它翻译成一句会出现在评论区的话——"这话不是在讲道理，是在贴标签。"

#### 症状三：帽子后面加理由

> "这就是典型的带节奏，因为他故意只引用了对自己有利的数据。"

AI 喜欢"定性 + 论证"的完整结构。但**帽子加理由就变成了批评**，批评是可以用证据反驳的。

**修法**：想要帽子，就别给理由；想给理由，就别用帽子。两者选一个。

#### 症状四：假具体

> "某些人总是喜欢在关键时刻发表一些不负责任的言论。"

"某些人""一些""关键时刻"——全是空槽。这种句子读起来像公文，打不到任何人。

**修法**：要么真具体（点名具体行为），要么干脆虚到底（"懂的都懂"）。**半虚半实最难看。**

#### 症状五：结尾升华

> "……这种现象值得每个人警惕。"

AI 有强烈的收尾冲动。但帽子不需要收尾，**帽子说完就走**。

**修法**：删掉最后一句。九成情况下删完更好。

#### 症状六：情绪与词汇不匹配

> "这种令人不齿的行径，实在让人深感遗憾。"

"不齿""行径""深感遗憾"是文雅词，配的是愤怒情绪。这种错配会让读者感到**说话的人不在场**。

**修法**：情绪愤怒就用短句和脏话的替代品（"就这？"）；情绪冷静就用平铺直叙。**词汇必须跟情绪同温。**

### 去 AI 味的三步操作

1. **砍一半**：删掉所有解释、收尾、排比的后半句
2. **换口语**：把"此类""具有""实质上"换成"这种""有""其实"
3. **加毛刺**：留一个不完美的表达——重复、省略、口语语病。**完美是 AI 的指纹。**

第三步最反直觉，也最有效。真人的句子有毛刺，AI 的句子没有。

### 与 anti-ai-flavor 的串行

```
hat_generate.py 产出
  → 手改（五技法 + 三步骤）
  → anti-ai-flavor 的 TEXT-001 ~ TEXT-008 检测
  → 再手改
  → 交付
```

`anti-ai-flavor` 能查出的：套话开头、空泛表述、过度结构化、虚假自信、AI 常用短语、信息空洞、重复赘述、虚假引用。

它查不出的：**毛刺**。毛刺只能手工加。

## 生成红线

四条，不可越。写在这里，也写在使用者心里。

### 一、不对真实个人

目标是**立场、行为、群体倾向**，不是姓名。

| 可以 | 不可以 |
|---|---|
| "某科技博主这波操作" | "张三这波操作" |
| "持这种观点的人" | "某个具体的人" |
| "某方案的设计" | "某工程师的设计" |

真实自然人 + 强度 3 帽子 = 网络暴力。**这不是修辞问题，是伤害问题。**

判定方法：**这句文案如果被对方看到，会不会造成实际困扰？** 会，就不能发。

### 二、不做群体仇恨

可以攻击观点，不可以把民族、地域、宗教、性别、残障、疾病当作帽子本身。

判据：**这顶帽子是否指向一个不可改变的属性？** 是，就越线了。

"观点错误"可以改，"出身"不能改。攻击不可改变的东西，本质上是让人为不是自己选择的事负责。

### 三、不涉未成年人

无例外。

### 四、不伪造证据

PAT-23 伪统计是**识别对象，不是生成作业**。

生成器不产出假数据、假截图、假引文、假时间线。这不是能力限制，是底线——**伪造证据的帽子不是帽子，是造谣**，而造谣的法律后果跟修辞后果不在一个量级。

违反任一条，本技能拒绝，并说明拒绝的理由，不给"技术上可行"的替代方案。

## 教学用法

生成器最大的价值不是造文案，是**做对照实验**。

### 用法一：同一帽子，三种强度

```bash
python3 scripts/hat_generate.py --target "某观点" --hat 巨婴 --intensity 1 --seed 1
python3 scripts/hat_generate.py --target "某观点" --hat 巨婴 --intensity 3 --seed 1
```

并排看，学生能立刻感到：**同一顶帽子，强度不同，可撤回性完全不同。** 这比讲十遍"注意措辞"有效。

### 用法二：同一句式，换帽子

```bash
python3 scripts/hat_generate.py --target "某人" --pattern PAT-02 --hat 收钱
python3 scripts/hat_generate.py --target "某人" --pattern PAT-02 --hat 带节奏
```

让学生看到：**句式是结构，帽子是填充物**。结构不变，攻击类型就变了。

### 用法三：生成后自拆

要求每个学生用生成器的 `counter` 字段，把自己刚生成的那条拆掉。**拆不掉说明没理解。**

这是本技能最推荐的教学法：**先扣，再拆，拆完再扣。** 三轮之后，"什么话能说，什么话说了会烂在自己手里"就变成了肌肉记忆。

## 交付前检查清单

- [ ] 家族只选了一个
- [ ] 强度与实际需要匹配（默认 1）
- [ ] 长度与平台匹配
- [ ] 没有解释、没有收尾、没有对称排比
- [ ] 有一个具体的、真实存在的靶点
- [ ] 有一条毛刺
- [ ] 过了 anti-ai-flavor 的文本维度
- [ ] 目标是行为/观点，不是真实姓名
- [ ] 没有指向不可改变的属性
- [ ] 自己能用一句话拆掉它（拆不掉就是没想清楚）

最后一条最狠，也最有用。**一条自己都拆不掉的文案，说明它不是帽子，是纯粹的恶意。**
