# 连招拆解

单式好拆，连招难拆。

原因不是连招更狠，是**拆掉一环，其余环仍在生效**。你把"收钱"那环拆了，对方还有"那路人"和"早晚报应"顶着；你把三环全拆了，围观者早就走了。

所以连招的处理逻辑和单式完全不同：**不要逐环拆，找最脆的一环，一击打穿整串。**

---

## 三种连招结构

### 递进式：一环否定一环的前提

```
动机（你收钱） → 身份（你就是那路人） → 时间（早晚报应）
```

每一环都在加固前一环，最后落到一个不可验证的判决上。这是最常见的结构。

拆法：**拆最前面那一环**。前面的环一倒，后面的环失去前提，会一起塌。

### 并置式：多个方向同时封死

```
道德（你做得出这种事） → 一致性（换成别人你早骂了）
```

两环互不依赖，各自独立封死一个方向。拆一环，另一环还站着。

拆法：**拆更具体的那个**。道德指控无法证伪，一致性指控可以列差异——先拆能列差异的。

### 闭环式：任何回应都被解释成认罪

```
举证（你证明我错） → 预设（你什么时候停止替他们说话）
```

两环合计封死四向：不回是默认，回是急了，举证是洗地，动怒是坐实。

拆法：**不做逐环拆解，只拆一次结构，然后停止。** 这类连招不产生可检验命题，追下去是纯消耗。

---

## CMB-01 三向封死

**构成**：动机归因 → 身份前置 → 时间审判

**实战样子**：收钱的吧，一看就是那路人，早晚遭报应。

**为什么这么排**：动机打头，因为它最便宜、最难证伪；身份居中，把攻击从行为转到人；时间收尾，给出一个永远不用兑现的判决。三步走完，被攻击者已经不是在辩论，是在接受审判。

**先拆哪一环**：动机。只做一件事——要证据，一句不解释。

**拆错会怎样**：先自证清白。一旦开始解释收入来源，后面的身份与时间审判全部自动生效，而且你越解释，围观者越觉得"这人反应这么大"。

**变体**：把时间环换成道德环（"早晚要还的"），或换成人身环（"这种人"），结构不变。

---

## CMB-02 稻草人加反问

**构成**：稻草人 → 反问压制

**实战样子**：你的意思就是什么都别管了？难道这还不够明显吗？难道大家看不出来？

**为什么这么排**：先把你改写成一个荒谬版本，再用连续反问把这个版本钉死。反问的数量制造"证据很多"的错觉，实际一个证据都没有。

**先拆哪一环**：稻草人。要求对方复述你的原话。

**拆错会怎样**：去反驳那个被扩写的版本。你赢了一个自己从没主张过的命题，而原文依旧没人读——这就是稻草人的全部收益。

**变体**：把反问换成"大家都这么觉得"，结构不变，气势弱一档。

---

## CMB-03 道德高地加双向标准

**构成**：道德高地占领 → 双向标准

**实战样子**：这种事你也做得出来？换成别人你早就骂了。

**为什么这么排**：先占据道德位置（你做得出这种事），再用一致性要求把你钉在原地（换成别人你早骂了）。前者让你不能辩解，后者让你不能沉默。

**先拆哪一环**：双向标准。列出两件事的关键差异，编号，三条以内。

**拆错会怎样**：先辩道德。道德高地上只能站一个人，抢的过程双方都会掉下来，而围观者记住的是"两个人都很激动"。

**变体**：把道德环换成"你也是有孩子的人"，共情式绑架，本质相同。

---

## CMB-04 贴标签加算沉默

**构成**：标签替换论证 → 沉默即认罪

**实战样子**：标准带节奏，问了三遍不敢答，心里有数了。

**为什么这么排**：标签负责定性，算沉默负责封死回应。注意后半句通常**捏造一个时间线**（"问了三遍"）——因为时间线看起来最像事实。

**先拆哪一环**：标签。摘掉标签，把原句还原成命题，请对方指出哪一项为假。

**拆错会怎样**：逐条解释。每条解释都是新靶子，而"问了三遍"这个造假没人去查——你忙着自证，等于替对方掩护了他自己的漏洞。

**变体**：把"问了三遍"换成"这么多人问你都不回"，同样是虚构的数量。

---

## CMB-05 借权威加取消资格

**构成**：诉诸权威 → 人身攻击

**实战样子**：这个问题专家早有结论，你也配讨论？

**为什么这么排**：权威负责关闭讨论，资格负责关闭人。两句话，一个提案就死了，而全场没有一个人提到方案内容。

**先拆哪一环**：权威。要具体——哪位专家、哪份文献、哪条结论。

**拆错会怎样**：强调自己的履历。资格赛永远赢不了，因为裁判是对方，而对方的标准可以随时改。

**变体**：会议场景里更常见的变体是"这个我们试过，不行"——不给时间、不给条件、不给数据，本质是同一个连招。

---

## CMB-06 群体连坐加以偏概全

**构成**：群体连坐 → 以偏概全

**实战样子**：跟那些天天骂的人有什么区别？看一眼评论区就知道了，果然都这样。

**为什么这么排**：先归类（你和他们是一伙的），再用一个样本证明这一伙都坏。归类不需要证据，样本只需要一张截图。

**先拆哪一环**：群体连坐。指出连接点是事实还是想象。

**拆错会怎样**：急着撇清"我跟他们不一样"。这等于接受了连坐逻辑，只是求个例外——而例外是可以随时被收回的。

**变体**：把"评论区"换成"你们都这样""你们那个圈子"，结构不变。

---

## CMB-07 上纲上线加词义膨胀

**构成**：上纲上线 → 词义膨胀

**实战样子**：这已经不是技术细节了，是大是大非，这操作堪称公开抢劫。

**为什么这么排**：先提升议题层级（细节 → 大是大非），再提升词汇当量（操作 → 抢劫）。两级抬升之后，原本的技术问题已经没人记得了。

**先拆哪一环**：上纲上线。要求先给出具体分歧的事实描述。

**拆错会怎样**：跟着宏大叙事走。一旦在"大是大非"层面应战，技术细节就再也回不来——这正是升级的目的。

**变体**：把"抢劫"换成"犯罪""屠杀""法西斯"，词汇当量越高，越容易显得滑稽，也越容易被截屏打脸。

---

## CMB-08 情绪劫持加反讽降维

**构成**：情绪劫持 → 反讽降维

**实战样子**：看到这种话血压直接上来了。不愧是人间清醒，建议直接颁奖。

**为什么这么排**：先用情绪定调（这值得愤怒），再用反讽取消你的严肃性（你不配被认真对待）。一句话让你既生气又滑稽。

**先拆哪一环**：情绪。把情绪句剥离，只处理事实句。

**拆错会怎样**：回怼情绪。情绪场是对方主场，你在他的规则里打，而且你越激动，反讽那环越有效。

**变体**：短评区的高频形态，长度通常不超过四十字，靠密度取胜。

---

## CMB-09 伪统计加时间审判

**构成**：伪统计 → 时间审判

**实战样子**：数据显示九成人都不同意，时间会证明谁对谁错。

**为什么这么排**：一个给当下权威（数字），一个给终极权威（历史）。两头都不给证据，但两头都不好反驳——数字要查出处，历史要等到未来。

**先拆哪一环**：伪统计。要来源、样本、问卷原文；指出没有基数的百分比无意义。

**拆错会怎样**：承认"也许以后会证明"。这等于把未发生的判决当成了已生效的判决，时间审判那环立刻收网。

**变体**：把"九成人"换成"圈内共识"，从统计伪装换成权威伪装，拆法相同：要具体。

---

## CMB-10 甩举证加预设攻击

**构成**：举证责任转移 → 语用预设攻击

**实战样子**：你什么时候才肯停止替他们说话？有本事拿出证据来。

**为什么这么排**：这是全部十条里唯一封死四向的一组。预设攻击让你无法回答（回答即承认预设），举证转移让你无法反驳（反驳即需要举证）。

**先拆哪一环**：语用预设。先拆出预设并明确否认——"这个问句预设了我在替谁说话，我不接受这个预设"。

**拆错会怎样**：任何形式的解释。四向全封：不回是默认，回是急了，举证是洗地，动怒是坐实。**这组连招唯一的正确处理是"拆一次，然后走"。**

**变体**：把"替他们说话"换成任何行为（"停止造谣""停止带节奏"），结构不变。

## 连招破法通则

三条，按优先级：

### 一、找最脆的一环

每条连招都有一环是纸做的。判断标准：**哪一环要求对方提供具体信息？** 那一环最脆。

- CMB-01 的纸环是动机（要证据）
- CMB-02 的纸环是稻草人（要复述）
- CMB-03 的纸环是双标（要列差异）
- CMB-05 的纸环是权威（要出处）
- CMB-09 的纸环是统计（要来源）

### 二、只拆一环，不拆全串

拆全串是送人头。三环全拆需要三百字，而围观者只读前两句。

拆一环，且拆得干净——让对方要么补上那一环（进入讨论），要么整串失效（围观者看清）。

### 三、四向封死的直接走

`seal_degree = 4` 的连招（CMB-10）不产生可检验命题。拆一次，说明结构，然后停止。**继续纠缠等于自愿当素材。**

## 自测

用扫描器验一下自己写的回复有没有踩到连招：

```bash
python3 scripts/hat_scan.py --file reply.md
```

命中的连招会以 `Critical`（封死 3 向以上）或 `Warning` 标注，并给出"先拆"提示：

```
!! L1  [Critical] CMB-01 三向封死  (连招)
     命中: HAT-F3-02 → PAT-14 → PAT-24
     机制: 连招 CMB-01：……封死 3 向回应路径
     反制: 只要求证据，一句不解释
     先拆: PAT-02   跨度 13 字
```

生成连招用：

```bash
python3 scripts/hat_generate.py --target "某博主" --combo CMB-01 --seed 3
```

输出会逐环标注用了哪顶帽子、哪个句式，拼接成完整一段，并附上破解步骤和"拆错会怎样"。

**教学用法**：让学生先看自己生成的连招，再让他用自己的话拆——拆不掉就是没懂。这比讲十遍"注意逻辑"有用。
